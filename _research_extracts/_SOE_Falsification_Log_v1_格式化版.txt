6. Key Findings
1. Trust is the central state variable and cannot be removed.
2. Control smoothing is the true stabilizing mechanism.
3. Threshold-based triggering is not required for stability.
4. Cognitive distortion amplifies disturbance but is not structurally necessary.
5. Recovery constraints can emerge from system stress.
7. Implications
The system is not a generic control system; it is trust-dependent.
Observed delay effects were artifacts of smoothing behavior.
The model now reflects underlying dynamics rather than simulation structure.

9. Final Statement
The falsification process identified the minimal set of mechanisms required for stability and eliminated several previously assumed components. The resulting system reflects a trust-centered dynamic stabilized by smoothed control under disturbance with constrained recovery.
