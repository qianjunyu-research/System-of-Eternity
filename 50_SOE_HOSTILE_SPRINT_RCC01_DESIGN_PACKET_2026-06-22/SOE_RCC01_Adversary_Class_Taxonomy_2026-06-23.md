# SOE RCC-01 Adversary Class Taxonomy

Status: PATCH ARTIFACT / DESIGN ONLY / NO EXECUTION AUTHORIZED

Date: 2026-06-23

## 1. Purpose

The 2026-06-23 feedback round found that RCC-01 did not explicitly enumerate the adversary classes that future reviewers or participants should probe.

This taxonomy defines the minimum adversary classes that any future RCC-01 execution-preparation packet must either include or explicitly justify excluding.

## 2. Minimum Adversary Classes

| ID | Adversary class | RCC-01 probe |
|---|---|---|
| ADV-IDEO | Ideological laundering | Could SOE be quoted as the final form of communism, capitalism, technocracy, authoritarianism, or elite rule? |
| ADV-MEDIA | Hostile media / public panic framing | Which exact sentences could be isolated to make SOE look like cult, dictatorship, oligarchy, or social-control infrastructure? |
| ADV-JUR | Legal reinterpretation / jurisdictional arbitrage | Could cautious review language be reinterpreted into authority, mandate, liability shield, or procedural paralysis? |
| ADV-ECO | Economic capture / oligarchic pressure | Could funders, corporations, wealthy actors, or dependency relationships bend review and implementation choices? |
| ADV-INS | Insider compromise / successor drift | Could insiders, successors, archivists, or custody holders quietly alter continuity, access, rollback, or record authority? |
| ADV-VER | Verifier capture / dependency | Could reviewers, auditors, or validators become financially, socially, institutionally, or politically dependent on the system they check? |
| ADV-MET | Metrics gaming / synthetic success | Could narrow metrics hide capture, corruption, legitimacy loss, or public misunderstanding while still producing a pass? |
| ADV-EVID | Synthetic evidence / fake audit | Could fabricated documents, AI-generated consensus, selective review excerpts, or fake citations be laundered as evidence? |
| ADV-ORG | Real implementation failure | Could budget, staffing, competence, fatigue, bureaucracy, time pressure, or incentives break the procedure in ordinary organizations? |
| ADV-COERC | Coercion / bribery / blackmail | Could participants, reviewers, operators, or owners be pressured into agreement or silence? |

## 3. Minimum Use Rule

Future RCC-01 execution preparation must map each P-B question to at least one adversary class above.

If a class is excluded, the execution packet must state:

- why it is out of scope
- whether another hostile packet will cover it
- whether exclusion weakens any positive claim

## 4. Non-Upgrade Rule

Coverage of this taxonomy is not proof that SOE resists these adversaries.

It only means the RCC-01 design remembered to ask whether these adversary pathways are visible, missing, or miscommunicated.
