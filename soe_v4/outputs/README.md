# Committed SOE v4 Outputs

This folder keeps compact, reviewable artifacts for GitHub:

- `soe_v4_report.md` and `soe_v4_summary.csv`: the first V4 scenario suite
- `claude_brief/`: the targeted Claude-brief validation reports and summary tables
- `full_campaign/`: the larger multi-phase campaign reports and summary tables

Large raw run CSVs are intentionally ignored by `.gitignore` and can be
regenerated locally from the committed Python runners.
