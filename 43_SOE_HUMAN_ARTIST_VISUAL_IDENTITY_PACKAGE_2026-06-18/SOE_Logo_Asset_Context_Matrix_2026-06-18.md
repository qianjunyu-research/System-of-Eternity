# SOE Logo Asset Context Matrix

This file records the practical asset system requested from a human artist. It exists because one logo image will not survive every public context cleanly.

## Core Principle

Design a flexible visual identity system, not a single static image.

The SOE mark should work across:

- small square avatars,
- profile pictures,
- website headers,
- paper covers,
- social preview cards,
- wide background banners,
- presentation title slides.

Different platforms crop images differently. The artist should define safe zones and produce format-specific exports rather than relying on aggressive resizing after the fact.

## Requested Asset Families

### 1. Primary Mark

- SOE wordmark or monogram.
- Full System of Eternity lockup.
- Must work in monochrome.
- Must remain readable in small sizes.

### 2. Avatar / Icon System

Recommended exports:

- 16 x 16 px
- 32 x 32 px
- 64 x 64 px
- 128 x 128 px
- 512 x 512 px
- 1024 x 1024 px

Use cases:

- GitHub avatar
- Substack avatar
- Discord/social avatar
- favicon
- small profile contexts

The 16 x 16 px and 32 x 32 px versions should be treated as simplified favicon tests. The mark does not need to preserve every detail at those sizes, but it must not collapse into a spinner, target, broken artifact, or unreadable acronym.

### 3. Wide Header / Banner System

Recommended exports:

- 1500 x 500 px for X/Twitter-style header use
- 1584 x 396 px for LinkedIn-style background use
- 1200 x 630 px for Open Graph / social preview use
- 2560 x 1440 px with safe-area guidance for YouTube/presentation/crop-heavy contexts

Use cases:

- social media header images
- website page banners
- research profile cover fields
- presentation backgrounds

### 4. Paper / Archive System

Recommended outputs:

- vector PDF mark
- SVG mark
- title-page lockup
- paper-cover version
- dark and light variants

Use cases:

- Zenodo/arXiv paper covers
- report title pages
- presentation title slides
- PDF front matter

### 5. Background / Wallpaper System

The background system should be quiet and secondary.

Good directions:

- subtle archival texture
- restrained structural linework
- minimal threshold or interval motif
- low-contrast pattern that can sit behind text

Avoid:

- loud wallpapers
- sci-fi scenes
- glowing networks
- cosmic/orbital imagery
- target-like geometry
- political or national imagery

## Safe-Zone Requirement

For every major asset family, the artist should provide a safe-zone note:

- what area must never be cropped,
- where text can safely sit,
- what version should be used for square vs wide vs document contexts.

## Final Practical Rule

The mark should not depend on one perfect crop. If it only works in one rectangle, it is not ready for public identity use.
