# Visual Identity Addendum Intake

Date: 2026-06-03

Source: `SOE_Visual_Identity_Report_with_Addendum.pdf`

Status: Intake note. This is not a final visual-identity verdict and does not freeze the website, logo, or SOE public identity.

## What The Addendum Changes

The addendum does not require redesigning the current website prototype. It strengthens the next logo/symbol phase by adding SOE-specific constraints that go beyond generic institutional credibility.

Core identity sentence:

```text
SOE is an open, modular, non-terminal civilizational architecture designed to preserve stability while allowing continuous institutional redesign.
```

## Primary Symbol Rule

The mark must not be closed.

Acceptable forms:

- Open lattice
- Interrupted orbit
- Modular gate
- Split pathway
- Non-closed node field
- Wordmark or monogram with an intentional opening

Reason:

- Non-terminality
- Right of exit
- Replaceability
- Upgradeability
- No final sealed system

## Topology Constraint

Avoid star-hub symbolism.

Do not use:

- One dominant center with subordinate nodes
- Command hub
- All-seeing center
- Sovereign ring
- Closed seal
- Globe-under-control imagery
- Military crest or state-seal posture

Prefer:

- Distributed peer-like nodes
- Multiple pathways
- Interrupted rings
- Open lattices
- Protocol architecture
- Archive grids
- Research-institute wordmark plus restrained abstract mark

## Recommended Direction

Recommended hybrid:

```text
Protocol Monogram + Open Lattice Gate
```

This means:

- A restrained wordmark remains the academic anchor.
- A small open node/lattice symbol carries SOE-specific meaning.
- The icon must work in one color and at favicon size.
- The symbol should look serious before it looks impressive.

## Candidate Design Directions

1. Conservative Academic Wordmark
   - Wordmark-first.
   - Maximum research credibility.
   - Possible open break in the O or modular cut in SOE letterform.

2. Open Lattice / Distributed Node Symbol
   - Abstract distributed-node architecture.
   - Visible exit path or opening.
   - No central hub.

3. Hybrid Wordmark + Open Node Architecture
   - Recommended final track if tests pass.
   - Wordmark plus minimal open lattice gate or nonterminal orbit.

## Palette Guidance

Use restrained institutional colors:

- Deep Institutional Navy: `#172A3A`
- Archive Blue: `#2F5D7C`
- Protocol Teal: `#2A7F7F`
- Warm Archive White: `#F6F4EE`
- Graphite: `#2B2F33`
- Muted Signal Amber: `#C8A45D`

Avoid:

- Heavy gold
- Black-red dominance
- Neon cyan or purple gradients
- Rainbow palettes
- Glossy 3D effects

## Typography Guidance

Approved families:

- Serif headings or wordmark: Source Serif 4, Charter, Merriweather, Libre Baskerville
- Body: Inter, IBM Plex Sans, Roboto, Source Sans 3
- Technical labels: IBM Plex Mono, JetBrains Mono

Avoid:

- Futuristic display fonts
- Gothic fonts
- Occult fonts
- Fantasy scripts
- Military stencil fonts
- Cyberpunk type
- Overly rounded startup fonts

## Required Quality Tests

Any future logo/symbol candidate must pass:

- Small-size / favicon test
- Black-and-white test
- No-cult test
- No-empire test
- No-sci-fi-faction test
- No-central-hub test
- Exit-visible test
- Research credibility test
- Family scalability test
- Non-terminal test

## Hard Rejection Criteria

Reject designs that:

- Use ornate, 3D, neon, mystical, militarized, fantasy, cyberpunk, or authoritarian visual language.
- Look like a political party, religious movement, secret society, AI corporation, state seal, military command, or game faction.
- Close the system into a perfect ring, total seal, pyramid, halo, or central command topology.
- Fail in black-and-white or at favicon size.
- Prioritize dramatic symbolism over public research credibility.

## Codex Design Task Later

When the logo phase begins, generate three constrained identity directions first, not a single finished logo:

1. Conservative Academic Wordmark
2. Open Lattice / Distributed Node Symbol
3. Hybrid Wordmark + Open Node Architecture

For each direction, include:

- Design rationale
- SVG-ready structural description
- Palette usage
- Typography pairing
- Layout examples
- Risks and failure modes
- Black-and-white adaptation
- Favicon adaptation
- Rejection criteria
