Psi_extended is not an enhancement for federation — it IS the monitoring system for federation. Psi_base alone is insufficient for federation because it does not capture cluster-internal divergence. Deployments on federation topology must use Psi_extended. lambda = 0.1 locked (v18 Sim 3, zero false positives, true_positive_rate = 1.0).
Psi_base(t) [ring/mesh/star/unknown]: Psi_base = w_T*(1-T_network) + w_D*D_effective + w_G*(1-G) + w_S*(1-S_network) + w_R*regime_weight Psi_extended(t) [federation — MANDATORY]: Psi_extended = Psi_base(t) + lambda * sum_k (N_k/N) * Var(T_{i in C_k}(t)) lambda = 0.1 [LOCKED — v18 Sim 3] Trigger A for federation fires on Psi_extended >= Psi_threshold, NOT on S_network >= S_threshold. S_threshold is irrelevant for federation topology.
