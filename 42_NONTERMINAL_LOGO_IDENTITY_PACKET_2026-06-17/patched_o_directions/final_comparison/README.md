# SOE Logo Final Comparison

Date: 2026-06-18

This folder responds to the second review round.

The earlier Variant 1 solved the reticle problem but introduced a new risk: the side gap could read as `SCE` instead of `SOE`. This set tests the corrected geometry:

- move the opening to the top / upper-right
- narrow the gap so the letter remains `O`
- improve S-O-E spacing
- test the divider with and without the center dot
- compare against a safer notched-O treatment

## Recommendation

Lead candidate:

`finalist-a-tuned-open-o-no-dot.svg`

Reason: it keeps the visible non-terminal signal while avoiding the four-gap reticle, side-gap C-read, and center-dot target cue.

Backup:

`finalist-c-notched-o-no-dot.svg`

Reason: it is safer and more typographic, but the non-terminal signal is quieter.
